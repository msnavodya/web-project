#  Web Project

This repository contains a beginner-friendly front-end web project built with HTML, CSS, JavaScript, and Bootstrap 4.

## Overview

The project collects several static web pages created during first year web development practice. It focuses on Bootstrap layout building, reusable components, image-based sections, and simple multi-page structure without a build step.

## Main Files

- `nsbmnew.html`: The most complete landing-page style layout with a navbar, carousel, search form, and content cards.
- `gallery.html`: A gallery-style page that reuses the Bootstrap layout and local image assets.
- `project 01.html`: An earlier Bootstrap prototype page used for experimenting with prebuilt components.
- `services 1`: A standalone services page with custom inline styling and two-column content cards.
- `NSBM.CSS`: Custom stylesheet used by the Bootstrap-based pages.
- `css/bootstrap-4.4.1.css`: Local Bootstrap stylesheet.
- `js/bootstrap-4.4.1.js`: Local Bootstrap JavaScript bundle.
- `js/jquery-3.4.1.min.js`: jQuery dependency for Bootstrap 4.
- `js/popper.min.js`: Popper.js dependency for Bootstrap dropdowns and overlays.
- `images/`: Project image assets used by the pages.

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap 4.4.1
- jQuery 3.4.1
- Popper.js

## Running The Project

There is no build or install step for this project.

1. Clone or download the repository.
2. Open `nsbmnew.html`, `gallery.html`, or `project 01.html` in a browser.
3. Open `services 1` directly in a browser if you want to preview the standalone services page.

## Notes

- This is a static student project intended for learning front-end fundamentals.
- Some pages are practice variations of the same Bootstrap layout rather than a single polished production site.
- The file named `services 1` has no `.html` extension, but it still contains HTML content.
