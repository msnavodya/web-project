#  Web Project

This repository contains a first year web development project built with HTML, CSS, and JavaScript.

## Project Overview

- `gallery.html`: Gallery page content.
- `nsbmnew.html`: Additional page for the website.
- `project 01.html`: Main project HTML file.
- `services 1`: Additional services content file.
- `NSBM.CSS`: Custom CSS styling for the project.
- `css/bootstrap-4.4.1.css`: Bootstrap 4.4.1 stylesheet.
- `js/bootstrap-4.4.1.js`: Bootstrap JavaScript.
- `js/jquery-3.4.1.min.js`: jQuery library.
- `js/popper.min.js`: Popper.js library.
- `images/`: Project image assets.

## How to Use

1. Open one of the HTML files in a browser.
2. Use the project pages and navigation links to explore the website.

## Notes

- This is a first year web project.
- The project uses standard front-end technologies and includes Bootstrap support.
